# Project briefing outline

Create `docs/codex-context.md` on attempt B using these headings. Replace prompts below with your own verified findings. This outline is not a completed deliverable.

## Purpose and users
What does this program calculate? Who benefits from the calculation? Distinguish a stated fact from an assumption about a larger application.

## File map and boundaries
Where are the calculation functions, pricing policy, tests, and AI instructions? Cite exact file paths and relevant function names. What must remain unchanged?

## Environment and verified commands
Record Python version and actual commands/results for both suites. Explain the expected initial acceptance failure. State whether dependencies, an installation step, a server, and lint commands exist; do not invent them.

## Conventions and rules
Explain money representation, permitted arithmetic, rounding, supported tiers, error behavior, and function boundaries. Cite the repository file supporting each rule.

## Requested improvement and acceptance criteria
Identify the exact function and scope. Summarize required behavior, including boundary cases, and how it will be checked.

## Uncertainties
List questions, how you resolved them, and any remaining uncertainty to resolve before editing. “None remain” is acceptable if you explain what you checked.
